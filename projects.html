Map Converter

Map Converter is an open-source online utility to convert Mercator Projection maps to Equirectangular Projection. It is written in Python, hosted on Streamlit Community Cloud, and built using Pillow. The code itself is on GitHub and is licensed under GPL-3.0. You retain the rights to all images you upload and all the images you download from the app, and everything you upload (as well as the converted map) is permanently deleted as soon as you leave the page. You can try it for yourself here!
